# Exercícios de POO em Java

Este repositório contém exercícios de **Programação Orientada a Objetos (POO)** desenvolvidos em Java.

## 📁 Estrutura do projeto

### 📂 Boletim + Aluno
Exercício envolvendo a criação da classe `Aluno`, com:
- Nome do aluno
- Duas notas
- Cálculo da média
- Verificação de aprovação ou reprovação
- Uso de métodos e objetos

### 📂 Hospital + Paciente
Exercício envolvendo a criação da classe `Paciente`, com:
- Nome
- Sexo
- Peso
- Altura
- Cálculo do IMC
- Uso de objetos e métodos

### 📂 Empresa + Funcionario
Exercício envolvendo as classes `Empresa` e `Funcionario`, com:
- Nome do funcionário
- Horas trabalhadas
- Valor da hora
- Cálculo do salário
- Desconto de previdência
- Instanciação de funcionários

## 🧠 Conteúdos praticados

Os exercícios foram desenvolvidos para praticar conceitos básicos de **Programação Orientada a Objetos em Java**, como:

- Classes
- Objetos
- Atributos
- Métodos
- `main`
- Entrada de dados
- Cálculos
- Estruturas condicionais
- Retorno de métodos
- Modificadores de acesso
- Representação UML

## 🛠️ Tecnologias

- **Java**
- **UML**
- **Git / GitHub**

O objetivo deste repositório é reunir os exercícios realizados durante os estudos de **POO em Java**, servindo como registro do aprendizado e da evolução na programação.
